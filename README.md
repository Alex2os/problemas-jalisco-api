## problemas-jalisco-api

to convert reports' latitude and longitude to a real ubication, the following api is used:
https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat=20.648822&lon=-103.319577&addressdetails=1

it works for the project for now, but no more than 1 request per second is allowed, as this is a free api.
